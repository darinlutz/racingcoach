# RacingCoach car drawings

Vehicle-specific engineering SVG drawings for RacingCoach, generated from licensed 3D models
with an orthographic feature-edge pipeline. 1 SVG unit = 1 mm.

Each car folder contains five views (left side, right side, top, front, rear), an anchors JSON
with normalized [0,1] coordinates (wheel centres, axles, contact patches, splitter/diffuser,
ride-height references), model-render reference PNGs, and validation notes.

Status: DRAFT, unverified against official homologation drawings. See each folder's
VALIDATION-NOTES.md for sources, licences, scaling and known limitations.

## Cars
- huracan-gt3-evo/ — Lamborghini Huracan GT3 EVO (wheelbase 2645 mm)
- ferrari-296-gt3/ — Ferrari 296 GT3 (wheelbase 2660 mm)
