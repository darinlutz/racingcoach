# iRacing setup exports (.htm)

Real garage setup exports written by the iRacing simulator, used by `scripts/car-setup-library.test.mjs` to test
`src/lib/setupHtm.ts` against several cars' boxes and labels (a GT3, a prototype, an F1 car, an MX-5 and a Skip Barber).

They come from the CarTunes project's test fixtures (https://github.com/parasyte/cartunes, `fixtures/`), MIT licensed,
Copyright (c) Jay Oster. Kept byte for byte.
